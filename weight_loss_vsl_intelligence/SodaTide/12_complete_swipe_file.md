## BANCO K — STORYTELLING STRUCTURES (ver Módulo 08)
1. **Ferida de origem:** lugar + objeto + voz de autoridade + sentença repetida ("Kmart… scale… my father… gonna be big").
2. **Espelho involuntário:** glimpse → freeze → not recognize → inventário → pergunta crua → número.
3. **Escada de tentativas:** 3 experts × (preço + protocolo + resultado + rebote + idiom).
4. **Dor relacional em espiral:** no more → gesto negado → comparação → traição → sozinha com cargas → máscara.
5. **Descoberta via pessoa de confiança:** "And that's when you came into my life."
6. **Relato com produto:** ceticismo ("I won't lie, uh") → "nothing left to lose" → ritual noturno → roupa folga → balança → número → espelho matinal → guarda-roupa.
7. **Depoimento-objeção:** cada convidada resolve uma objeção e fecha com frase-síntese.
8. **Depoimento completo (Susan):** "die fat" → desistência → filha → "last hope" → tamanhos → vestido guardado → frase do marido → choro invertido.
9. **Compradora ao vivo:** arrependimento de comprar pouco + "credit card in my hand" + "spoiler alert".
